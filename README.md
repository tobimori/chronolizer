# Chronolizer

A planned Effect library for bidirectional conversion between natural-language date ranges and a portable date-filter format.

The format is owned by Chronolizer. Elasticsearch date math is syntax inspiration, not a compatibility requirement.

## Status

The Vite+ library workspace and Effect v4 test environment are ready. The temporal AST and public API will be implemented after the design review.

## Development

```bash
vp install
vp test --run
vp check
vp pack
```
